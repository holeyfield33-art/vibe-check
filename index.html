What it checks

Focused on the signals that deserve a closer look.

The scanner stays narrow on purpose. It surfaces concrete review signals, not a blanket security verdict.

Syntax Errors

Python files that do not parse cleanly.

Undeclared Imports

Imports that are missing from declared dependencies.

Typosquat Lookalikes

Dependency names that resemble known packages too closely.

Duplicate Code

Repeated blocks that show up across files.

Dead Code

Stubs and top-level definitions nothing references in-repo.

Structural Signals

Deep nesting, giant files, and circular imports.

Disposition is not a score

The disposition is based on scanner findings. It is not a quality score, trust score, or AI-likelihood score.

Deterministic and offline

Demo reports are generated by the real vibe-check CLI. The website only renders the resulting JSON.

What vibe-check is not

Not a general security platform

Vibe Check is not a comprehensive SAST platform, a CVE database, a secret scanner, a penetration test, or an AI-authorship detector.

Why it exists

It is a deterministic review and triage layer designed to surface specific signals that deserve developer attention.
